# 3 安装Zabbix
## 3.1 创建zabbix用户
```bash
addgroup --system --quiet zabbix 
adduser --quiet --system --disabled-login --ingroup zabbix --home /var/lib/zabbix --no-create-home zabbix
```

## 3.2 获取软件包并安装
```bash
# 下载zabbix安装包
wget https://cdn.zabbix.com/zabbix/sources/stable/6.0/zabbix-6.0.X.tar.gz

# 解压安装zabbix
tar zxvf zabbix-6.0.*.tar.gz 
cd zabbix-6.0.*/

# 编译安装
export CFLAGS="-std=gnu99"
./configure --prefix=/usr/local/zabbix --enable-server --enable-agent --with-mysql --enable-ipv6 --with-net-snmp --with-libcurl --with-libxml2
# ./configure --prefix=/usr/local/zabbix --enable-server --enable-agent --with-mysql --enable-ipv6 --with-net-snmp --with-libcurl --with-libxml2 --enable-webservice
make install
```

## 3.3 zabbix数据库配置
```bash
# 创建数据库数据目录
systemctl stop mariadb
mv /var/lib/mysql/ /var/lib/mysql_bak/
mkdir -p /data/mysql/
ln -s /data/mysql/ /var/lib/
chown -R mysql:mysql /data/mysql/

# 配置Mysql（mariadb）
vi /etc/mysql/my.cnf
...
# 需要额外添加配置（zabbix需求）
[mysqld]
expire_logs_days=7
max_binlog_size=500M
innodb_file_per_table=1

# 启动数据库
systemctl start mariadb
systemctl enable mariadb

# 如果无法启动可尝试重置数据库
rm -rf /var/lib/mysql/*
mysql_install_db
chown -R mysql:mysql /var/lib/mysql/*
systemctl start mysqld
```

## 3.6 收尾工作
### 3.6.1 zabbix服务启动脚本
**采用init.d方式启动**
```bash
# 配置启动脚本
cd zabbix-6.0.*/misc/init.d/fedora/core/

cp * /etc/init.d/
sed -i "s#BASEDIR=.*#BASEDIR=/usr/local/zabbix#" /etc/init.d/zabbix_server
sed -i "s#BASEDIR=.*#BASEDIR=/usr/local/zabbix#" /etc/init.d/zabbix_agentd

# 配置服务自启动
service zabbix_server start
service zabbix_agentd start
chkconfig zabbix_server on
chkconfig zabbix_agentd on
```

**采用systemd方式启动**
zabbix_server服务
```bash
cat > /etc/systemd/system/zabbix_server.service << EOL
[Unit]
Description=Zabbix Server
After=syslog.target network.target mariadb.service
 
[Service]
Type=oneshot
User=zabbix
ExecStart=/usr/local/zabbix/sbin/zabbix_server
ExecReload=/usr/local/zabbix/sbin/zabbix_server -R config_cache_reload
RemainAfterExit=yes
PIDFile=/var/run/zabbix_server.pid
 
[Install]
WantedBy=multi-user.target
EOL
```

zabbix_agent服务
```bash
cat >  /etc/systemd/system/zabbix_agentd.service << EOL
[Unit]
Description=Zabbix Agent
After=syslog.target network.target
 
[Service]
Type=oneshot
User=zabbix
ExecStart=/usr/local/zabbix/sbin/zabbix_agentd
RemainAfterExit=yes
PIDFile=/var/run/zabbix_agentd.pid
 
[Install]
WantedBy=multi-user.target
EOL
```

配置服务自启动
```bash
systemctl daemon-reload
systemctl start zabbix_server
systemctl start zabbix_agentd
systemctl enable zabbix_server
systemctl enable zabbix_agentd
```

# 5 snmpwalk使用
```bash
参数说明：
-c  团体名
-v  snmp 版本
-l  认证类型
-u  snmpv3用户
-a  鉴权协议，默认为MD5
-A  鉴权密码
-x  传输加密协议
-X  传输加密密码
```

## 5.1 snmpv2使用示例
```bash
snmpwalk -v 2c -c 6cL%B7vn/~hM94+Z 100.64.3.128
snmpwalk.exe -v 2c -c ZW_bjaudit_for_zabbix 127.0.0.1
```

## 5.2 snmpv3使用示例
```bash
snmpwalk -v 3 -l authPriv -u admin -a SHA256 -A '&6K?rB64Pt4^dJz@' -x AES -X '6cL%B7vn/~hM94+Z' 100.64.3.218
# 不知道为啥，&6K?rB64Pt4^dJz@ 密码必须使用单引号引住才能正常验证，而zabbix上配置该密码无法验证。怀疑是不支持某些特殊字符
```
